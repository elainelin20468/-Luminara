## 权杖牌组（火元素🔥）

> 整体：权杖 = 火 = 激情、欲望、挑战、创造力  
> 星座：白羊座、狮子座、射手座  
> ⚠️ 警告：权杖骑士 = 渣男代表；权杖国王 = 自私自我

| 牌 | 正位关键词 | 感情/事业 | 逆位含义 | 对方怎么想 |
|----|-----------|----------|---------|-----------|
| **权杖1** | 新的火花、启发、潜力爆发 | 强烈情欲，激情关系 / 新事业机会 | 创意受阻，热情消散 | 对你有强烈欲望，被你的活力吸引 |
| **权杖2** | 两难抉择、展望未来、思考 | 思念过去或有两个情人 / 两份机会 | 害怕未知，裹足不前 | 在考虑是否要继续追你，还在观望 |
| **权杖3** | 远见、扩张、等待成果 | 为爱付出，正在收获 / 机会在远方 | 计划受阻，需要重新规划 | 对你有期望，在等待时机 |
| **权杖4** | 庆祝、家庭、欢聚 | 浪漫喜事，聚会邂逅 / 工作获认可 | 不稳定，家庭/感情出现裂缝 | 以你为荣，想要和你一起庆祝 |
| **权杖5** | 冲突、竞争、纷争 | 感情充满争吵，被动冲突 / 竞争激烈 | 避免冲突，但矛盾未解决 | 对你有竞争心，想争夺你的注意力 |
| **权杖6** | 胜利、荣耀、暂时的成功 | 庆祝感情喜悦 / 战胜对手 | 骄傲自满，领先优势不稳 | 想在你面前表现自己，展示成就 |
| **权杖7** | 捍卫立场、逆境中坚持 | 为感情奋斗 / 应对挑剔环境 | 放弃立场，无法坚守 | 在保护这段关系，抵御外界干扰 |
| **权杖8** | 快速行动、好消息即将来 | 迅速坠入爱河，控制冲动 / 消息来了 | 行动受阻，信息传递出错 | 对你充满热情，想快速推进 |
| **权杖9** | 疲惫但坚守、历经考验 | 过去伤痛影响信任 / 职场压力大 | 放弃坚守，崩溃或偏执 | 曾受过伤，对你有防御心，但在努力 |
| **权杖10** | 重担、压力过大、疲惫 | 感情进入考验期 / 被压垮 | 无法承担，彻底放下（或逃跑） | 感到压力，但愿意为你承担 |
| **权杖侍从** | 新想法萌发、好奇、年轻活力 | 给恋人空间成长 / 升职消息 | 冲动莽撞，说大话不行动 | 充满好奇，想多了解你 |
| **权杖骑士** | ⚠️ **渣男代表**！行动力强、冒险、只想玩 | 寻求短暂刺激，没有长期打算 / 快速行动 | 鲁莽冲动，没有方向 | **只想继续娱乐，不想负责任** |
| **权杖女王** | 强势女性、超直觉、向日葵能量 | 自信有魅力，吸引力强 / 以智慧应对挑战 | 控制欲强，嫉妒心爆发 | 被你的自信吸引，但也在评估你 |
| **权杖国王** | ⚠️ **自私自我**！热情领袖表面（白羊座） | 表面值得信赖，实则自我中心 / 天生领袖但独断 | 暴君作风，不听他人 | 把自己放在第一位，感情里也不例外 |

> 整体：钱币 = 土 = 金钱、工作、物质生活、现实  
> 星座：金牛座、处女座、摩羯座

| 牌 | 正位关键词 | 感情/事业 | 逆位含义 | 对方怎么想 |
|----|-----------|----------|---------|-----------|

| **钱币3** | 团队合作、技能认可、学习 | 实际行动推进感情 / 努力得到认可 | 缺乏合作，工作不达标 | 想向你展示自己的能力和价值 |
| **钱币4** | 守护、稳定、吝啬、抓紧 | 稳定关系，但可能太过封闭 / 守住既有成果 | 财务浪费，或对改变敞开心扉 | 想保住这段关系，不想失去你 |
| **钱币5** | 贫困、被遗弃、困难时期 | 感情中感到被忽略 / 经济困难 | 走出困境，有人伸出援手 | 感觉在感情中很孤独，缺乏安全感 |
| **钱币6** | 给予、慷慨、平衡交换 | 在感情中给予和接受平衡 / 获得奖励 | 债务问题，不平等给予 | 想给你支持，但也希望得到回报 |
| **钱币7** | 评估、等待收获、长远眼光 | 投入时间看感情是否值得 / 评估成果 | 缺乏远见，急于求成 | 在评估这段感情是否有未来 |
| **钱币8** | 专注技能、勤奋、精益求精 | 努力经营感情，付出时间 / 全力以赴 | 对工作感到厌倦，缺乏进步 | 在认真地对待这段关系，踏实付出 |
| **钱币9** | 独立丰盛、自给自足、成就 | 独立自主，不依赖感情 / 财务独立 | 过度物质，或依赖问题 | 觉得你非常有魅力和独立，很欣赏 |
| **钱币10** | 家庭传承、财富积累、长久 | 婚姻家庭幸福美满 / 事业财务顶峰 | 家庭纠纷，财务损失 | 把你看作长期伴侣，想要共同建立 |
| **钱币侍从** | 机遇的种子、认真学习 | 感情慢慢发展，脚踏实地 / 新项目开始 | 不切实际，学习不够认真 | 认真学习和投入，对你有好感，慢慢靠近 |
| **钱币骑士** | 缓慢可靠、忠诚、踏实 | 稳定可靠但行动慢 / 稳扎稳打 | 固执停滞，不知变通 | 动作缓慢但忠诚，需要耐心等待，但不会消失 |
| **钱币女王** | 贤惠务实、滋养、现实 | 踏实可靠，感情认真，注重实质 / 实际支持 | 物质化，过度担忧安全感 | 踏实可靠，感情认真，想要有实质性的感情进展 |
| **钱币国王** | 成功商人、物质稳定、摩羯座 | 重视稳定和物质，用实际行动表达爱 / 财务成功 | 贪婪守财，用金钱控制他人 | 重视稳定和物质，感情中会用实际行动（礼物/资源）表达爱 |
