# 塔罗牌解读技能

## 核心解牌哲学

> 塔罗不是算命，是照镜子——看清自己的能量状态

解牌时，首先判断问题类型（感情/事业/综合），然后查阅对应参考资料。

## 解牌流程

```
1. 明确问题类型（感情 / 事业 / 综合）
2. 识别牌的类型（大卡 / 小卡 / 宫廷牌）→ 读取对应参考文件
3. 判断正逆位
4. 多张牌时：看牌组比例 + 大卡优先 + 查组合含义
5. 结合"对方怎么想"栏目分析人物心理（如有需要）
6. 输出：关键词 + 感情/事业含义 + 建议 + 记忆钩
```

---

## 快速规则

- **大卡出现 = 重大课题**，优先解读大卡
- **圣杯多 = 感情为核心**；**宝剑多 = 有冲突需沟通**；**钱币多 = 物质现实层面**；**权杖多 = 行动期**
- **恋人牌**：95%情况代表三角关系或选择困难，非单纯爱情
- **逆位也有积极牌**：恶魔逆（挣脱束缚）、月亮逆（真相大白）
- **宝剑10的背景永远有太阳**——谷底之后必有重生
